### 升级过程中发现并修复的问题

**问题 1（中等优先级）：vite.config.ts alias 路径未跟随 0.2.0 monorepo 重构**

- **现象**：`pnpm build` 报 `Could not load /main-ui/src/vue/styles/main-ui.css`
- **根因**：matheshop 的 `vite.config.ts` 中有 3 条硬编码 alias（`main-ui/styles.css`、`main-ui/core`、`main-ui/vue`），路径指向 `../main-ui/src/...`（monorepo 重构前的旧路径），实际源码已在 `../main-ui/packages/main-ui/src/...`
- **修复**：将 alias 路径更正为 `../main-ui/packages/main-ui/src/...`
- **建议**：在 `HOST_UPGRADE_CHECKLIST_TEMPLATE.md` 中增加"检查宿主 vite.config / webpack resolve 中 main-ui 相关 alias 路径是否需要跟随 monorepo 重构"检查项

**问题 2（中等优先级）：workspace 同名包冲突**

- **现象**：`pnpm-workspace.yaml` 同时包含 `../main-ui`（根包 name `main-ui` v0.0.0）和 `../main-ui/packages/*`（含 `packages/main-ui` name `main-ui` v0.6.0）时，Vite 优先解析到根包（无 `src/`）
- **修复**：从 workspace packages 中移除 `../main-ui`（根包），仅保留 `../main-ui/packages/*`
- **建议**：在迁移指南中明确说明——workspace 联调时不应同时将 monorepo 根包和子包纳入下游的 workspace packages
